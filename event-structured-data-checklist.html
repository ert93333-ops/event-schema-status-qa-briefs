Event schema QA

Status, time, location, and offers

Event status, timezone, venue/online location, tickets, visible copy, organizer, and owner handoff.

Checklist

Run these checks before publishing event markup.

1. Confirm event status

Check EventScheduled, EventPostponed, EventRescheduled, EventCancelled, or sold-out language against the visible event banner and ticketing state.

2. Check dates and timezone

Confirm startDate and endDate match visible copy and include the intended timezone or offset when the event time is specific.

3. Match venue and online details

Compare visible venue address, room, livestream, virtual URL, and hybrid event handling against Event location and attendance mode.

4. Review ticket offers

Confirm offers.url, price, priceCurrency, availability, and stale ticket links before launch or date changes.

5. Document organizer and performer facts

Assign organizer, performer, speaker, or venue fact owners where they affect public event details.

6. Assign cleanup owners

Assign event marketing, ticketing, venue, content, frontend, and SEO owners before publishing. This checklist is technical QA, not legal or ticketing advice.

Handoff

Copy this prelaunch prompt.

"Please confirm Event JSON-LD status, start/end date, timezone, venue or online location, ticket offer URL, price, availability, visible status copy, organizer/performer facts, and remediation owners before launch."
